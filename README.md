# Telecom Customer Churn Analysis

## Overview
Exploratory data analysis and churn prediction on 7,043 telecom customer records using Python.

## Key Findings
- Overall churn rate: 20.56%
- Month-to-month contracts, electronic check payments, and senior citizens show the highest churn
- Longer-tenure customers are retained best

## Model
- Logistic Regression (scikit-learn)
- Accuracy: 80.4% | ROC-AUC: 0.84

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## Files
- `python_Project_Customer_Churn_Data_Analysis.ipynb`: analysis notebook
- `customer_churn_dataset.csv`: dataset
